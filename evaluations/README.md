# evaluations

Test harnesses, benchmarks, and pass/fail criteria used to measure whether a
skill actually does what it claims — before it's trusted in the library and
whenever it's revised.

Expected to eventually hold, per skill (or per skill category): task
definitions, scoring/grading logic, and recorded results across versions so
regressions are visible.

This is about measuring a skill's *effectiveness*. Compliance/safety/quality
review of a skill's content belongs in [`audits/`](../audits) instead.

Empty for now — no skills exist yet to evaluate.
